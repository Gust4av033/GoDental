# DEV-07 · Referencia visual de interfaz

## Decisión

Las dos composiciones compartidas por el usuario el 18 de octubre de 2026 sirven como guía de apariencia para GoDental: fondo claro, superficies blancas, acento azul, navegación lateral compacta, encabezados discretos y tarjetas de lectura rápida. El modo oscuro conserva la misma estructura con los tokens existentes.

La referencia muestra módulos, métricas, imágenes de producto, códigos de barras y gráficos que todavía no tienen contratos o datos implementados. Esta fase aplica el patrón visual a acceso, inicio, productos, categorías, ajustes y diálogos existentes. Las cifras y funciones futuras no se simulan en la interfaz operativa.

Se actualizan los tokens compartidos; los colores siguen sujetos a la definición final de identidad visual de UX-01. El logotipo ilustrado en la referencia no se incorpora como activo hasta contar con un recurso aprobado.
